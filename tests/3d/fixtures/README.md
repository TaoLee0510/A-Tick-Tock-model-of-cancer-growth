# Legacy checkpoint identity fixtures

These fixtures were generated by compiling the unmodified configuration code
from commit `8bb39cd8aa93d2ff9f15c4643127fda950e9a92a` with Apple clang.
The inputs are `atcg3d_smoke_test_v3.yaml`, `nutrient_smoke_v1.yaml`, and
`continuum_smoke_v1.yaml`. Output paths do not enter dynamics identity.

`legacy_smoke_dynamics.json` is the exact ABM dynamics string. The two lines of
`legacy_smoke_fingerprints.txt` are the nutrient v1 and continuum v1 unsigned
64-bit fingerprints, respectively. The compatibility test also verifies that
explicit new model choices and nondefault parameters change identity.
